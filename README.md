# SPDjangoPro

## 环境搭建

1.  **创建虚拟环境**:
    ```bash
    python3 -m venv venv
    ```

2.  **激活虚拟环境**:
    - macOS/Linux:
      ```bash
      source venv/bin/activate
      ```
    - Windows:
      ```bash
      .\venv\Scripts\activate
      ```

3.  **安装依赖**:
    ```bash
    pip install -r requirements.txt
    ```

## 运行项目

```bash
python manage.py runserver
```
